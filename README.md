# World Radio Tuner
A web app that lets you explore and listen to live radio stations from around the world, visualised on an interactive map.

Live demo

## Features

- Detects your location and loads your country automatically
- Click any country on the map to load radio stations from there
- Scans for a working stream automatically — skips dead streams and retries until it finds one
- Shuffle button picks a random country and starts playing
- Save up to 3 preset stations for quick access
- Share a link to any station with a friend
- Switch between satellite and street map views

## Tech stack

### Frontend
JavaScript, jQuery, Bootstrap, Leaflet.js
### Backend
PHPRadio, Radio Browser API

## How to run

This project requires a PHP server. Clone the repo and serve it from a local PHP environment such as XAMPP
`
bashgit clone https://github.com/yourusername/world-radio-tuner
`
Then open in your browser via your local server.
